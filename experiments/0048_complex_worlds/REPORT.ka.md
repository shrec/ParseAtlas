## მეორე defect, გზაში ნაპოვნი

არსებული key-ს `"R"` არ არის domain restriction. ის symbol assumption-ია, და ეს ორი რამ ერთმანეთს სცილდება.

ნამდვილად ჭეშმარიტად თვლის. დაინსტალირებულ SymPy-სთან ეს `x**2 + 1`-ისთვის მუშაობს, რომელიც ცარიელ სიას
აბრუნებს, და `x**4 + 3*x**2 + 3`-ისთვის ვერ მუშაობს, რომელიც ოთხ არანამდვილ ფესვს აბრუნებს:

```text

of those, non-real                                 4
```

მიმართულებას მნიშვნელობა აქვს და სწორედ ამიტომ არის ეს აქ გამჟღავნებული და არა დამარხული. leak-ს შეუძლია

## Sweep: სივრცეს კედლის პოვნის უფლება

`operator_count` არის computational limit და არა threshold, და მრუდი ქვეყნდება და არა წერტილი. ანბანი ხუთი
ატომია — `x`, `1`, `2`, `(x * x + 1)`, `(x * x + 2)` — ოთხივე operator-ით, რაც `5^(n+1) * 4^n` source-ს იძლევა.

divisor-signature screen აშორებს იმ source-ებს, სადაც 25-ივე grammar divisor subtree-ების ერთსა და იმავე
დალაგებულ სიას იძლევა; მათ თითო domain-ში ერთი მუდმივი excluded tuple აქვთ, ამიტომ მათ verdict-ს მხოლოდ
canonical form წყვეტს. ეს არის **screen და არა თეორემა** — ის სანდოა მხოლოდ იმ შემთხვევაში, თუ `simplify`
25 წაკითხვას ორივე assumption set-ის ქვეშ ერთნაირად აჯგუფებს — ამიტომ ის კონტროლდება და არ ენდობა: `n = 1`
და `n = 2`-ზე ყოველი გასხვლილი source ხელახლა გამოითვალა ძვირი გზით.

|---|---|---|---|---|---|---|---|
| 1 | 100 | 90 | 10 | 100 | 0 | 0 | 0 |
| 2 | 2000 | 1395 | 605 | 1998 | 2 | 0 | 0 |
| 3 | 40000 | 21060 | 18940 | 39684 | 316 | 0 | 0 |


## Half B: branch cut როგორც მეორე convention

### Convention-ები, დეკლარირებული

convention არის სხივი საწყისი წერტილიდან; `arg` აიღება ნახევრად ღია ინტერვალში `(cut, cut + 2*pi]`, ასე რომ
თვით cut სხივი ეკუთვნის იმ branch-ს, რომელსაც საათის ისრის საწინააღმდეგოდ ვუახლოვდებით. ოთხია
დეკლარირებული, და SymPy-ის default **დასახელებულია მათგან ერთად**, და არა უსახელოდ გამოყენებული:

| name | cut | where the cut lies | arg interval | SymPy default |
|---|---|---|---|---|
| `principal` | `-pi` | the negative real axis, `arg = pi` | `(-pi, pi]` | yes |
| `negative_imaginary` | `-pi/2` | the negative imaginary axis, `arg = -pi/2` | `(-pi/2, 3*pi/2]` | no |
| `positive_axis` | `0` | the positive real axis, `arg = 0` | `(0, 2*pi]` | no |
| `positive_imaginary` | `pi/2` | the positive imaginary axis, `arg = pi/2` | `(pi/2, 5*pi/2]` | no |

`principal` იმეორებს SymPy-ის საკუთარ `sqrt`-სა და `log`-ს `9` საზონდო მნიშვნელობაზე, `18` შემოწმება,
`0` წარუმატებლობა. უსახელო default არჩევანი კი არა, შემთხვევითობაა; ეს კი არჩევანია და ის ახლა ჩაწერილია.

module-ში არსად არცერთი branch-ის გადაწყვეტილება float-ით არ მიიღება. არგუმენტის შედარება მიდის ზუსტ
რაციონალურ სუროგატზე, *diamond angle*-ზე, რომელიც `arg`-ს `(-pi, pi]`-დან `(-2, 2]`-ზე ასახავს და `k*pi/4`-ს
`k/2`-ში გადაიყვანს, ზუსტად, ყოველი Gaussian rational-ისთვის.

### სად დევს თითოეული cut, დაკვირვებით და არა დეკლარაციით

convention იდენტიფიცირდება არა სახელით, არამედ იმ სხივით, რომელზეც მისი branch წყვეტილია. თითოეული cut
გადაკვეთილია ზუსტი რაციონალური წყვილით რადიუსზე `4`, და შემოწმებულია **ორივე**, `sqrt` და `log`, რადგან
convention, რომელიც მხოლოდ ერთს ამოძრავებდა, საერთოდ არ იქნებოდა branch convention. წყვეტილობის ტესტი
ნიშნის ტესტია და არა სიდიდის შედარება: `sqrt`-ისთვის `f(above) * conj(f(below))`-ის ნამდვილი ნაწილი
უარყოფითია ზუსტად მაშინ, როცა sheet ტრიალდება; `log`-ისთვის ორი branch ლოგარითმის სხვაობას შეუძლია
მიისწრაფოდეს მხოლოდ `0`-ისკენ ან პლუს-მინუს `2*pi*i`-სკენ, ამიტომ `pi` მათი ზუსტი შუაწერტილია და ის
სტრუქტურულია და არა მორგებული.

## Half C: reducibility `C`-ზე

manager-მა owner-ის მათემატიკოსისთვის გაზომა, რომ „ფესვები გვერდზე" უპირატესობა არსებობს ზუსტად მაშინ, როცა
quadratic იშლება `Q`-ზე. აქ ის თავიდან არის გამოყვანილი:

| quadratic | roots | Q | R | C | factored writing in Generation 1 | expanded cheaper | factored cheaper | tie |
|---|---|---|---|---|---|---|---|---|
| `2 * x * x + 3 * x - 5` | `-5/2`, `1` | yes | yes | yes | `(2 * x + 5) * (x - 1)` | 9 | 8 | 8 |
| `x * x - 2` | `-sqrt(2)`, `sqrt(2)` | no | yes | yes | none | 13 | 8 | 4 |
| `x * x + 1` | `-I`, `I` | no | no | yes | none | 13 | 8 | 4 |

პირველ სტრიქონში `8` არის manager-ის რიცხვი, რეპროდუცირებული. `13` და `4` სტრიქონები აფასებენ factored
**ფორმას** დასახელებული ფოთლით, რომელიც ცვლის იმ რიცხვს, რომლის დაწერაც ენას არ შეუძლია; ისინი ფორმის
ღირებულებას ზომავენ და ობიექტის ჩაწერა არ არიან.

**რას ყიდულობს უფრო ფართო domain და რას არა.**

```text
quadratics that factor over Q                             1 of 3
quadratics that factor over R                             2 of 3
quadratics that factor over C                             3 of 3
quadratics with a factored writing in the language        1 of 3, over every domain
what C buys for the EQUIVALENCE                           2 more
what C buys for the NOTATION                              0
```

`C`-ზე სამივე იშლება, ასე რომ equivalence ორს იგებს. notation არაფერს იგებს, და მიზეზი დაკვირვებულია და არა
მტკიცებული, რადგან მისი მტკიცება მცდარი იქნებოდა. `i` **არის** ლეგალური token Generation 1-ში — როგორც
*ცვლადის სახელი*:

| attempt | parses | canonical form | intended | denotes it |
|---|---|---|---|---|
| `(x - i) * (x + i)` | yes | `-i**2 + x**2` | `x**2 + 1` | no |
| `(x - r) * (x + r)` | yes | `-r**2 + x**2` | `x**2 - 2` | no |
| `i * i` | yes | `i**2` | `-1` | no |

```text
attempts                3
that parse              3
that denote the object  0
```

ასე რომ „Generation 1-ს `i`-ს დაწერა არ შეუძლია" ასე ნათქვამი მცდარია და ნაგულისხმევი აზრით ჭეშმარიტი.
tokeniser string-ს იღებს, parser tree-ს აგებს, და გამოსული canonical form თავისუფალ symbol `i`-ს ატარებს და
არა წარმოსახვით ერთეულს. შეზღუდვა **აღნიშვნაშია** და არა სიმბოლოთა ნაკრებში, და სწორედ ეს ხაზი აინტერესებს
half C-ს.

კიდევ ერთი observation ორ მხარეს სუფთად ჰყოფს. იმ სამყაროების რაოდენობა, სადაც factored ᲤᲝᲠᲛᲐ უფრო იაფია,
სამივე quadratic-ისთვის `8`-ია, იმისგან დამოუკიდებლად, რომელი ველი აწვდის ფესვებს. ფრჩხილების დათვლა ფორმას
კითხულობს; ის არასოდეს ეკითხება, სად ცხოვრობს ფესვები. მეორე მხრივ excluded set საპირისპიროს აკეთებს — სამი
reciprocal-იდან მხოლოდ `1 / (x * x + 1)` იგებს რამეს `C`-ზე:

```text
1 / (2 * x * x + 3 * x - 5)     R  ('-5/2', '1')            C  ('-5/2', '1')
1 / (x * x - 2)                 R  ('-sqrt(2)', 'sqrt(2)')  C  ('-sqrt(2)', 'sqrt(2)')
1 / (x * x + 1)                 R  ()                       C  ('-I', 'I')
```
