`triangle_area` და `chain_rule` მასში შედიოდნენ, თუმცა თითოეულს ერთი თვისება აქვს. თვისობრივი დასკვნა
არ იცვლება, რიცხვი გასწორდა.) ხოლო ორი თვისება — `constant_term` და `roots` — **არასოდეს, არცერთ სამყაროში, არცერთ
object-ზე არ ჩანს ერთად**; ეს არ არის წესების მიერ აკრძალული წყვილი, ეს არის გაზომვა.

ეს არის card-ის შინაარსი: representation-ის შეცვლა არა მხოლოდ **ფასს** ცვლის (0034, 0037), არამედ იმას,

`-5/2` და `1`, 25-იდან **17 სამყაროში** ყველაზე იაფად იწერება როგორც `2 * x * x + 3 * x - 5` (ჩანს

`(2 * x + 5) * (x - 1)` (ჩანს ფესვები; თავისუფალი წევრი და უფროსი კოეფიციენტი **არ** ჩანს).

### Rule-relativity: ეს პირველ სექციაშია და არა შეზღუდვებში

**„Manifest" აქ ნიშნავს ზუსტად იმას, რასაც ამ მოდულში დეკლარირებული shape რულები ამბობენ, და ყველა
რიცხვი მათზეა ფარდობითი.** სხვა, ისევე დამცავი წესების ნაკრები რიცხვებს გადაანაცვლებდა. ამიტომ ორი
regime გაზომილია და ორივე გამოქვეყნებულია:

```text
transparent (მთავარი)   ფრჩხილი პუნქტუაციაა: სამყაროს მკვიდრი კითხულობს string-ს საკუთარი
                        grammar-ით და ამიტომ tree უფასოდ აქვს; უფასოდ არ აქვს ალგებრა.
                        სამყარო მაინც წყვეტს რას ხედავ — რადგან ის წყვეტს რომელი ჩაწერაა იაფი.
opaque (robustness)     ფრჩხილი ვიზუალური კაფსულაციაა: მასში ჩაწერილი ერთეულია და წესს არ
                        შეუძლია შიგნით ჩაიხედოს. აქ grammar ორჯერ მოქმედებს — ირჩევს ჩაწერას
                        და წყვეტს რამდენია ფრჩხილებში.
```

## Manifestness-ის წესები

წესები ერთ დისციპლინას ემორჩილება, გამონაკლისის გარეშე: წესი არის **shape test ჩაწერილ ფორმაზე**. მას
შეუძლია წაიკითხოს token-ები, დათვალოს ისინი და ნახოს როგორ არიან დაჯგუფებული. მას **არ** შეუძლია
ალგებრა — არც გახსნა, არც factoring, არც მსგავსი წევრების შეკრება, არც ამოხსნა. თუ თვისების გადაწყვეტა
გამოსახულების გადაწერას მოითხოვს, თვისება manifest არ არის.

Vocabulary დახურულია და შვიდწევრიანია. ხუთი მათგანი **principal variable**-ზეა და ის **დეკლარირებულია**
და არა გამოთვლილი (`PRINCIPAL_VARIABLES`): მისი დადგენა („ყველაზე ხშირი ცვლადი") განსჯა იქნებოდა
გაზომვის სახით ჩაცმული.

| თვისება | shape რული (ჩაწერილ ფორმაზე) | algebraic control |
|---|---|---|
| `degree` | monomial-ების ჯამია და ცვლადი გვხვდება (ხარისხი = მისი გამეორებები ყველაზე გრძელ monomial-ში), **ან** ნამრავლია, რომლის მამრავლები ცვლადში მაქსიმუმ წრფივია (ხარისხი = ცვლადის მატარებელი მამრავლების რაოდენობა) | object არის polynomial ამ ცვლადში |
| `leading_coefficient` | monomial-ების ჯამია და **ზუსტად ერთი** monomial აღწევს უმაღლეს ხარისხს | polynomial ამ ცვლადში |
| `constant_term` | monomial-ების ჯამია და **მაქსიმუმ ერთი** monomial არის ცვლადისგან თავისუფალი | polynomial ამ ცვლადში |
| `roots` | ზედა operator მამრავლობითია, ყოველი მნიშვნელი ცვლადისგან თავისუფალია, ყოველი მრიცხველი არის leaf ან ცვლადში წრფივი monomial-ჯამი (ზუსტად ერთი წრფივი წევრით) | polynomial ხარისხით >= 1, რომლის ფესვები სრულ ხარისხს ფარავს |
| `factor_structure` | ზედა operator არის `*` და მისი მრიცხველი მამრავლებიდან **ორი მაინც არ არის leaf** | object-ს აქვს ორი მაინც არაკონსტანტური მამრავლი |
| `sign_structure` | ზედა დონე არის >=2 შესაკრების additive ჯაჭვი და ყოველი შესაკრები monomial-ია | გახსნილ object-ს აქვს >=2 წევრი |
| `even_parity` | monomial-ების ჯამია და **ყოველი** monomial ცვლადს ლუწჯერ ატარებს | `v -> -v` არ ცვლის object-ს |

### სამი გადაწყვეტილება, რომლებიც დეკლარირებულია და არა ნაგულისხმევი

**1. ფესვის წაკითხვა წრფივი მამრავლიდან ითვლება კითხვად და არა ალგებრად.** `2 * x + 5`-იდან `-5/2`-ის
აღება ერთი ნიშნის შეცვლა და ერთი გაყოფაა ხილულ token-ებზე. Card-ის შემოთავაზებული რული („top level is a
product of factors each linear in the principal variable") სწორედ ამას გულისხმობს, და ეს არის ის განსჯა,
რომელიც calibration case-ს card-ის ფორმულირებით ამოაგდებს.

**2. `roots` მოითხოვს, რომ object ნამრავლად იყოს წარმოდგენილი.** `m * x + b` არის კოეფიციენტების სია
და არა ფაქტორიზაცია; მისგან ფესვი გამოსაყვანია. ნამრავლისთვის კი ეს წარმოდგენა თავად ფესვების
წარმოდგენაა. ეს ხაზი დეკლარირებულია, ტესტით არის დაპინული და mutation-ით შემოწმებული.

**3. Card-ის შემოთავაზებული `constant_term` რული გასწორდა.** „top level is a sum with a leaf constant
addend" **არასწორია**: `fa - dfa * a + dfa * x`-ს ორი ცვლადისგან თავისუფალი შესაკრები აქვს და მისი
თავისუფალი წევრი მათი ჯამია. ერთზე თითის დადება მცდარია, ორის შეკრება კი ალგებრა. ამიტომ რული არის
„**მაქსიმუმ ერთი** ცვლადისგან თავისუფალი შესაკრები".

### Control: manifest => true, და მეტიც — წაკითხული მნიშვნელობა სწორია

`ground_truth` იგივე თვისებებს **ალგებრულად** ითვლის (SymPy: factor, expand, solve, subs). ეს არის
control, და ის განზრახ საპირისპირო ტიპის გამოთვლაა. მაგრამ სუსტი control („თვისება არსებობს") არ არის
საკმარისი, ამიტომ `value_audit` უფრო შორს მიდის: ყოველი manifest ჩაწერისთვის ის ამოიღებს იმ
**მნიშვნელობას**, რომელსაც მკითხველი წაიღებდა — ხარისხს, უფროს კოეფიციენტს, თავისუფალ წევრს, ფესვების
multiset-ს — და SymPy-სთან ადარებს.

```text
manifest => true       1700 უჯრედი (34 x 25 x 2 regime),  2573 claim,   0 დარღვევა
წაკითხული მნიშვნელობა   2156 შემოწმება,                                  0 შეუსაბამობა
```

## Corpus

**Corpus იმპორტირებულია და არა ხელახლა შექმნილი.** ეს არის 0037-ის დასახელებული კანონების corpus
(`parseatlas.domain_worlds.CORPUS`, 33 კანონი, 4 field) პლუს card-ის calibration კვადრატული.

```text
objects            34        writings           50        two-sided   16
imported laws      33        one-sided          18        fields       4
canonical sources   OK       identities hold    OK        principal variable declared for 21
```

`canonical_sources` ნიშნავს, რომ ყოველი source string უკვე მინიმალური rendering-ია control grammar-ში.
`identities_hold` ნიშნავს, რომ ორმხრივი კანონის ორივე მხარე SymPy-ის მიხედვით **ერთი და იმავე
object-ია** — რაც აუცილებელია, რადგან სწორედ ეს ხდის სამყაროს არჩევანს არჩევანად და არა ორ სხვადასხვა
საგანს შორის შედარებას.

Object-ს, რომელსაც ერთი ჩაწერა აქვს, სამყაროსთვის ასარჩევი არაფერი აქვს; 16 ორმხრივ object-ს კი აქვს, და
**16-ვე ნამდვილად იხრება** — თითოეულს 25 სამყაროში ორივე ჩაწერა ერთხელ მაინც იმარჯვებს.

## Null model

Object, რომლის manifest set ყველა სამყაროში ერთია, **ვერავითარ დასკვნას ვერ ატარებს**: ის ყველა
სამყაროს ერთსა და იმავეს უმატებს.

```text
constant manifest set (25-ვე სამყაროში ერთი)      18 / 34   — ზუსტად ერთჩაწერიანი object-ები
constant rendered text (25-ვე სამყაროში ერთი)      1 / 34   — chain_rule (dfg * dg)
forced total (მათი წვლილი ყოველ სამყაროში)              28
movable subcorpus                                       16
```

მათი ამოღების შემდეგ: **ranking-ის რიგი იდენტურია სიმბოლო-სიმბოლოთ**, `G0`-ის rank უცვლელი (`1`), spread
უცვლელი (`19`). ანუ ranking კონვენციებს ზომავს და არა corpus-ის მოცულობას. Opaque regime-ში constant
manifest set-იანი object-ები მხოლოდ `5`-ია (ფრჩხილების განლაგება იქ თავადაც ცვლის ხილულობას), forced
total `0`, და დასკვნა იგივეა.
