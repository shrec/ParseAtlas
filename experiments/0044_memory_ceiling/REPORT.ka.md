## რა იზომება და რა არ არის `peak_live`

`peak_live` ითვლის **values-ს და არა bytes-ს**. ეს არის Sethi-Ullman register number — Ravi Sethi და Jeffrey D.
Ullman, *The Generation of Optimal Code for Arithmetic Expressions*, JACM 17(4), 1970 — და აქ ის ციტირებულია
როგორც კლასიკური შედეგი, რაც არის, და არა როგორც ამ პროექტის გამოგონება. წესი: leaf-ს სჭირდება `1`; node-ისთვის,
თუ ორ subtree-ს სხვადასხვა რაოდენობა სჭირდება, პასუხი უფრო დიდია, ხოლო თუ ერთი და იგივე სჭირდებათ, პასუხი არის ეს
პლუს ერთი, რადგან უფრო მძიმე მხარე პირველად გამოითვლება და მეორე მხარის ერთადერთი გადატანილი მნიშვნელობა მას peak-ში
ვერასდროს დაემთხვევა.

`peak_live`-ის owner-ის ტერაბაიტებზე ასახვა გულისხმობს, რომ ცოცხალი მნიშვნელობები შედარებადი ზომისაა. **ეს არის
