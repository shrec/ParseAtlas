# კვადრატული განტოლება 25 კონვენციაში

**წყარო:** ექსპერიმენტები [0035](../experiments/0035_alternative_mathematics/REPORT.md), [0037](../experiments/0037_domain_worlds/REPORT.md), [0038](../experiments/0038_manifest_properties/REPORT.md), [0039](../experiments/0039_visibility_ceiling/REPORT.md).
**ინგლისური ვერსია:** [quadratic-in-25-conventions.en.md](quadratic-in-25-conventions.en.md)
**აუდიტორია:** მათემატიკოსი პროექტის გარედან.

ოპერატორთა პრიორიტეტი **კონვენციაა და არა თეორემა**. თუ ის სხვანაირად შეთანხმდებოდა, სტანდარტული ჩანაწერი `a·x·x + b·x + c` სხვა ობიექტს აღნიშნავდა — და შესაძლო სამყაროების თითქმის ნახევარში კვადრატული ფორმულა საერთოდ არ იარსებებდა.

## 1. დაყენება

ოთხ ბინარულ ოპერატორს `+ − * /` აქვს `4! = 24` მკაცრი პრიორიტეტული დალაგება. მათ ემატება ჩვენი კონვენციური გრამატიკა `G0`, სადაც `*` და `/` ერთ დონეზეა, ხოლო `+` და `−` — მათ ქვემოთ. სულ **25 კონვენცია**.

ასოციაციურობა ყველგან მარცხნიდან მარჯვნივაა, ფრჩხილი ყველგან გადაფარავს პრიორიტეტს, და სიმბოლური გამარტივება ხდება *მხოლოდ* გარჩევის შემდეგ — რომ გრამატიკა და ალგებრა არ აირიოს.

## 2. მთავარი შედეგი

ერთი და იგივე ჩანაწერი, რომელსაც ყველა სამყარო დაწერდა:

```text
a * x * x + b * x + c
```

25 კონვენციაზე ის იძლევა **ზუსტად ორ** სხვადასხვა მათემატიკურ ობიექტს:

| | 13 კონვენცია (მათ შორის `G0`) | 12 კონვენცია |
|---|---|---|
| აღნიშნავს | `a·x² + b·x + c` | `a·x·(b + x)·(c + x)` |
| ხარისხი | 2 | 3 |
| ფესვები | `(−b ± √(b² − 4ac)) / 2a` | `0`, `−b`, `−c` |
| რას მოითხოვს | დისკრიმინანტი, რადიკალი, დასაზეპირებელი ფორმულა | არაფერს — ფესვები კოეფიციენტებიდან იკითხება |

იმ 12 სამყაროში სტანდარტული პოლინომი **უკვე დაშლილი მოდის**. იქ არც დისკრიმინანტი იქნებოდა, არც `b² − 4ac`, არც კვადრატული ფესვი — და არც კვადრატული ფორმულა, როგორც სასწავლო ერთეული. მათი „რთული" ნაბიჯი პირიქით იქნებოდა: **ფრჩხილების გახსნა**.

## 3. ფიქსირებული ამოცანა

წინა სექცია *ჩანაწერს* აფიქსირებს. ახლა პირიქით: დავაფიქსიროთ *ამოცანა* და ვნახოთ, როგორ ჩაიწერებოდა იგი სხვაგან.

```text
2x² + 3x − 5 = 0        →        x = 1,   x = −5/2
```

ორივე ჩანაწერი ერთსა და იმავე ფუნქციას აღნიშნავს. მინიმალური ფრჩხილების რაოდენობა თითო კონვენციაში:

| ჩანაწერი | იაფია სამყაროთა რიცხვში | ფრჩხილი `G0`-ში |
|---|---|---|
| `2*x*x + 3*x − 5` (გახსნილი) | 9 | 0 |
| `(2*x + 5)*(x − 1)` (დაშლილი) | 8 | 2 |
| ფასი ერთია | 8 | — |

**რვა სამყაროში დაშლილი ფორმა უფრო იაფად იწერება.** იქ ამ ამოცანის ჩაწერა უკვე მისი ამოხსნაა — ფესვები `−5/2` და `1` პირდაპირ ჩანაწერშია. სირთულე არ ქრება; ის **ადგილს იცვლის**.

> **შენიშვნა კონვენციაზე.** 0038 ტოლ ფასს გახსნილის სასარგებლოდ არღვევს, ამიტომ იქ იგივე შედეგი 17/8-ად იკითხება. აქ სამმხრივი დაშლაა მოცემული, რომ ტოლი შემთხვევა ხილული იყოს.

ეს განზოგადდება: 15 ორმხრივი კანონიდან **13** იბრუნებს ბუნებრივ მიმართულებას სადმე, და 25-იდან **22 სამყაროს** აქვს სულ მცირე ერთი შებრუნება. დისტრიბუციულ კანონზე `G0`-ში გახსნილი მხარე 0 ფრჩხილს ითხოვს და დაშლილი — 2; `G01`-ში ზუსტად პირიქითაა.

## 4. რას ხედავს თითო ჩანაწერი

კვადრატულ `2x² + 3x − 5`-ს ექვსი შემოწმებადი თვისება აქვს. **ვერცერთი კონვენცია ვერ აჩვენებს ოთხზე მეტს ერთდროულად.**

| ჩანაწერი | ჩანს | იმალება |
|---|---|---|
| `2*x*x + 3*x − 5` | ხარისხი · უფროსი კოეფიციენტი · თავისუფალი წევრი · ნიშნები | ფესვები · დაშლის სტრუქტურა |
| `(2*x + 5)*(x − 1)` | ფესვები · დაშლის სტრუქტურა | თავისუფალი წევრი · უფროსი კოეფიციენტი |

34 ობიექტსა და 25 სამყაროზე გაზომვამ ორი შედეგი მოგვცა.

**პირველი:** ვერცერთი სამყარო ვერ აჩვენებს ვერცერთი მრავალთვისებიანი ობიექტის ყველა თვისებას ერთდროულად — **0 უჯრედი 625-იდან**.

**მეორე, უფრო ვიწრო და უფრო მკვეთრი:**

```text
თავისუფალი წევრი და ფესვები ერთად არასდროს ჩანს — 0 უჯრედი 850-იდან
```

ეს **გაზომვაა და არა განსაზღვრების არტეფაქტი**: იგივე წესები *უშვებენ* ორივეს ერთად სინთეზურ ჩანაწერზე. ანუ სამყარო, სადაც ფესვები ჩანს, თავისუფალ წევრს მალავს — და პირიქით. არჩევანი გარდაუვალია.

დამოუკიდებელი გაზომვა იმავე მიმართულებით: რვა ტრიგონომეტრიულ იგივეობაზე `G0` საუკეთესო სამეულშია, და პითაგორას იგივეობა `s·s + c·c` გადარჩება ზუსტად იმ **13** სამყაროში, სადაც `*` წინ უსწრებს `+`-ს.

## 7. შეზღუდვები

- ენა შეიცავს მხოლოდ ბინარულ `+ − * /`-ს და ფრჩხილებს. ხარისხი, რადიკალი და ფუნქციის გამოძახება არ არსებობს, ამიტომ ზოგი ჩანაწერი შემცვლელ სიმბოლოებს იყენებს.
- „ჩანს" განისაზღვრება ჩვენივე გამოცხადებული ფორმის წესებით. სხვა წესები ციფრებს გადააადგილებდა — თუმცა შემოწმდა: *გაცვლა* გადარჩა წესების ცვლილებას, *დათვლა* — არა.
- კორპუსი ხელით არჩეულია და ასახავს განსჯას იმის შესახებ, რომელი კანონია ფუნდამენტური.
- ფრჩხილების რაოდენობა ერთი საზომია. კითხვის სირთულე და უნარული მინუსის პრიორიტეტი მის გარეთაა.
- **უხილავი ≠ არარსებული.** 140 ჭეშმარიტი (ობიექტი, თვისება) წყვილიდან 46 არცერთ 25 ჩანაწერში არ ჩანს. ისინი გამოთვლით დადგინდა და არა ჩანაწერიდან — სწორედ ესაა ამ მეთოდის საზღვარი.
- **და ის საზღვარი გავზომეთ.** 0039-მა გახსნა *სრული* parenthesization space — 1 510 820 ხე, ყოველი შესაძლო დაფრჩხილვა — და 46-იდან დაიბრუნა **ზუსტად ერთი**, ისიც precedence-ით მიღწევადი, ანუ ჩვენივე მოდელის ხარვეზი და არა ფართო სივრცის მოგება. მიზეზების რეალური დაშლა:

  | რატომ არ ჩანს | წყვილი |
  |---|---|
  | ვიწრო სივრცე | 1 (და ისიც ხარვეზი) |
  | ენა — არც რადიკალი, არც `i` | 8 |
  | თვით ხილვადობის წესები | 37 |

  ანუ 46-იდან **0** მოითხოვს ხეს, რომელსაც precedence ვერ წერს. დაფრჩხილვის ბარიერი აქ არაფერს ხსნის — ბრალი თითქმის მთლიანად წესებსა და ენაზეა.
