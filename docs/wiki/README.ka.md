# ParseAtlas-ის ვიკი

[English](README.md) · [ვიკის მთავარი](README.ka.md)

ParseAtlas არის კვლევითი პროექტი მათემატიკური გამოსახულებებისა და პარსერების შესახებ: როგორ ცვლის გრამატიკის არჩევანი ინტერპრეტაციას. იგი ადარებს ეკვივალენტურ მათემატიკურ ჩანაწერებს და კითხულობს, იძლევიან თუ არა ისინი ერთსა და იმავე პარსინგის შედეგსა და მნიშვნელობას, და როგორ შეიძლება მათი გამოცხადებული ღირებულება მაინც განსხვავდებოდეს. ამ ვიკიში გამოცხადებული ღირებულება ნიშნავს მკაფიოდ დასახელებულ საზომებს, როგორიცაა ფრჩხილების წყვილები, ხის სიღრმე და პიკური ცოცხალი შუალედური მნიშვნელობები. იგი არ ნიშნავს დაშვებებს, ავტორის ძალისხმევას, შემოწმების ტვირთს ან დაუსახელებელ ბენჩმარკის შედეგს.

ეს ვიკი არის მცირე პირველი გამოცემა, რომელიც ამ საცავში ეტაპობრივად ვითარდება. ის ახალ მკითხველს პროექტში შესვლის გზას აძლევს მანამდე, სანამ დეტალურ ანგარიშებს დაეყრდნობა. არსებული ანგარიშები და სპეციფიკაციები ავტორიტეტულად რჩება; ეს მთავარი გვერდი არ იმეორებს მათ რაოდენობებს, სტატუსის ცხრილებს, დასრულების განცხადებებს ან ექსპერიმენტულ შედეგებს.
