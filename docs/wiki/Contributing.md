# Contributing to Wiki Growth

[Home](README.md) | [ქართული](Contributing.ka.md)

## Purpose

Grow this Wiki in small, source-first increments while keeping English and Georgian pages equivalent. The proposed sequence is: next write `1` worked example, then improve experiment navigation and expand the glossary, then add `1` validated reproducibility walkthrough. These are proposed Wiki increments only; they are not launched tasks, completed work, findings, or benchmark results.

## Evidence and policy

Use the [roadmap](../../ROADMAP.md) and dated [roadmap audit](../roadmap-audit.md) for phase evidence. Do not copy or recompute phase totals on this page. Follow the [documentation policy](../DOCUMENTATION_POLICY.md). Claims need a source link, or an explicit label: `Hypothesis`, `Model`, or `Result`.

## Update process

Update authoritative source content first: the roadmap entry, audit note, experiment note, or existing Wiki source. Then update the Wiki explanation and both translations in the same change. Keep quantities, limitations, uncertainty, and status wording the same across languages. Verify relative links after editing, including home, reciprocal language switch, roadmap, audit, policy, and related pages.

## Reusable page outline

Use this outline whenever a page answers a narrow repository question rather than a broad overview.

- Question
- Explanation / example
- Evidence + source
- Scope / limitations
- Related pages
- Next question

## Scope

This page is a maintenance guide for gradual Wiki growth. It does not duplicate old reports.
