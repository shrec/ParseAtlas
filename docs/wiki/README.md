# ParseAtlas Wiki

[ქართული](README.ka.md) · [Wiki home](README.md)

ParseAtlas is a research project about mathematical expressions and parsers: how grammar choices change interpretation. It compares equivalent mathematical writings by asking whether they produce the same parse and meaning, and how their declared cost can still differ. In this Wiki, declared cost means explicitly named measures such as parenthesis pairs, tree depth, and peak live intermediates. It does not mean assumptions, author effort, validation burden, or an unstated benchmark result.

This Wiki is a small first edition developed gradually inside this repository. It gives new readers a route into the project before they rely on detailed reports. Existing reports and specifications remain authoritative; this home page does not copy their counts, status tables, completion claims, or experimental results.
